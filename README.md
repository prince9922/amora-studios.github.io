Replace the four `ADD IMAGE` blocks with actual product images when you are ready.

- Coffee Mugs
- Frames
- Keyrings
- Bottles

For the hero image, replace the `.hero-art` placeholder in index.html with:
<div class="hero-art"><img src="assets/images/hero.jpg" alt="Amora Studios personalised gifts"></div>

with:
<div class="product-image"><img src="assets/images/your-image.jpg" alt="Product name"></div>
