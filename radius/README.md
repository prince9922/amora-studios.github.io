# Radius Event App — Enhanced Frontend Prototype

This is a frontend-only prototype for Radius, the location-first event discovery app.

## What's included
- Black + dark-green Radius visual system
- Space Grotesk + DM Sans typography
- Participant / Organizer / Admin role selection at entry
- Simulated role permissions and separate dashboards
- Event imagery stored locally under `assets/events/`
- Participant event discovery with search and filters
- **Radar Search** page with animated sweep, configurable 5/10/15/25 km radius, matching event dots and result list
- Event detail modal with description, date, start/end time, location, distance, capacity, price and mini map
- Organizer event creation, approval flow, attendees and analytics demos
- Admin moderation, user/organizer management, reports and analytics demos
- Responsive desktop/tablet/mobile layout

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

All data is dummy data. The radar/map is a visual prototype and does not use live GPS or a mapping API yet.
